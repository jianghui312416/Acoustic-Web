# 海洋声场分析前端

基于 Vue 3、Vite、ECharts 和 Cesium/GeoVis 的海洋声场分析前端。

## 开发与验证

```bash
npm install
copy .env.example .env.local
npm run dev
```

交付前执行：

```bash
npm run check
```

## 目录职责

```text
src/
├─ api/                 通用网络层和各业务领域接口
├─ components/
│  └─ layout/           顶部导航、左侧子模块导航等通用界面
├─ config/              模块目录、部署运行配置
├─ layouts/             应用外壳
├─ modules/             复杂业务模块的数据模型与专属逻辑
├─ plugins/             第三方库的按需注册与统一初始化
├─ sdk/                 声场解析与 Cesium 渲染能力
├─ utils/               无界面依赖的数据转换和辅助方法
└─ views/               一级业务视图
```

`App.vue` 只负责模块选择与视图装配，`ApplicationShell.vue` 负责通用布局，
`AcousticFieldView.vue` 负责水声传播业务。新增模块时不要继续把业务代码堆进
`App.vue` 或 `AcousticFieldView.vue`。

## 阵列信号多域联动

顶部选择“阵列信号”可进入时频域、波束域和声场态势的统一时间轴展示。模块默认
使用可重复的本地演示帧，因此后端未启动时也可直接查看完整联动效果。

如需接入 `SouthSea_SonarDetect.html` 使用的实时波束服务，在 `.env.local` 中配置：

```dotenv
VITE_ARRAY_FUSION_WS_URL=ws://127.0.0.1:8888/ws/array-fusion
```

实时帧兼容 `frame`、`t`、`az_true`、`az_peak`、`range_km`、`snr`、`detected`、
`event` 和 `curve` 字段，并使用 `frequencies_hz`、`spectrum_db` 绘制实时阵元时频图。
连接中断时界面自动回退至演示数据并定时重连。接口随 `backend_worker.py` 一起启动。

## 新增一级模块

1. 在 `src/views/` 新建业务视图，复杂模块可在 `src/modules/<module-name>/` 下组织专属组件与状态。
2. 在 `src/config/moduleCatalog.js` 登记模块、子模块和 `viewKey`。
3. 在 `src/App.vue` 的 `viewRegistry` 中登记 `viewKey` 与业务视图的对应关系。
4. 在 `src/api/` 下新增该业务领域的接口文件，复用 `httpClient.js`，不要在组件内直接调用 `fetch`。

## 新增现有模块的子模块

1. 在 `moduleCatalog.js` 对应模块的 `children` 中增加稳定的英文 `id` 和中文展示名。
2. 由对应业务视图接收 `activeSubmoduleId`，按 id 切换面板或功能组件。
3. 子模块包含独立表单、结果或状态时，创建独立 Vue 组件；不要只为了增加菜单项而创建空组件。

## 接口联调

复制 `.env.example` 为 `.env.local`，按环境设置：

```dotenv
VITE_PORTAL_API_URL=http://127.0.0.1:8888/
VITE_API_TIMEOUT_MS=120000
```

环境地址不写进组件或提交到仓库。`api/httpClient.js` 处理网络、JSON 和超时，
`api/soundFieldApi.js` 处理声场门户的 SN、Plugin、ResultCode 和业务错误。

## 区域地形与声场悬浮窗口

- 第一次点击地形图标自动加载当前声源附近的区域，左下角保留可移动、缩放选框的缩略图；右侧箭头可隐藏或恢复缩略图。
- 全球视图缩放到区域后显示红色选框：拖动框体只平移、不改变大小，拖拽角点/边可缩放；点击选框后在下方出现「加载」，点击后进入地形模式并加载所选区域。选框按屏幕像素工作，拖动时不会因透视产生尺寸变化；选区跨过 180° 经线或覆盖极区时会提示先转动地球到目标海域。
- 地形区域使用以选区左下角海面为原点的三条参考轴：经度、纬度方向和垂直向下的深度轴；每条轴 6 个刻度、无箭头，深度轴从海面 0 m 到区域最深点。
- 在地形模式继续向外滚轮，缩放到最小时地形整体淡出，数字地球先定位到同一区域再以该区域为中心飞回全球视角，避免突然跳回。缩回后关闭三维结果窗、隐藏声场体/二维投影/声线/图例，保持与首次进入页面一致的干净全球视图；此时不显示红框，继续放大到阈值后红框才出现在刚才的区域中心，点击红框或下方「加载」返回刚才的地形（保留原视角）。转动地球或拖动红框后转为新选区。
- 侧栏收起后保留运行、全球、地形、展开和模块图标。品牌与视图图标采用紧凑尺寸。
- 运行自动进入地形视图，使用现有三维计算接口；计算成功后，将真实 TL 数据按经纬度、距离、方位、深度投影在海底上方。拖动旋转，滚轮缩放。
- 声源上方菜单提供运行、二维声场、参数设置图标。参数窗口复用原有三维参数；最小化后保留顶部恢复按钮。
- 二维按钮同时打开可拖动的动态传播损失剖面和声速剖面，使用同一次计算的声线与 `reconstructDataVS` 数据。无数据时显示空态，不合成计算结果。
- 海底使用 Terrarium 编码的有符号高程（负值表示海底），显示高程色标和悬停水深。服务失败时保留上次成功区域或显示重试提示，不再将影像或模拟高程当作真实水深。
- 开发环境通过 Vite `/bathy` 代理读取 AWS Terrain Tiles；生产环境直连公开服务，或通过 `VITE_BATHYMETRY_TILE_URL` 配置内部同格式瓦片服务。数据源归属链接显示在底部状态栏。地形和声场为带垂向夸张的透视展示，数值标签保留实际米数。

### 地形站点信息

在区域地形内部单击可选取站点；拖动仅旋转地形。信息卡显示水深、经纬度和取整风速，展开后显示详细风速、气象来向与降雨。卡片的运行按钮复用左侧运行流程，参数按钮将所选坐标载入现有三维参数窗口；噪声按钮暂为禁用占位。

站点数据通过 `GetEnvDataStation`（SN 22）获取，使用当前数据集和查询时间：`DT_ENV_10m_WIND_U`、`DT_ENV_10m_WIND_V`、`DT_ENV_RAIN`。风速为 U/V 合成值；降雨单位读取 `GetDataTypeMetaInfo`，累积量不冒充小时雨强。缺测和请求错误独立显示，不替换为零。后端须正确配置降雨对应的 NetCDF 变量和单位。

### 地形加载容错与默认取景

默认区域宽高约为声场直径的三倍，保留周围地形，不改变计算传播距离或压缩声场坐标。
地形请求在主图和缩略图之间共用最多 4 个并发连接；失败瓦片自动重试一次，区域仍失败则最多回退两级分辨率。
较低分辨率会在地形标题中标明。新区域未成功加载时不将新声场叠加到旧区域，避免裁剪后铺满旧选框。
